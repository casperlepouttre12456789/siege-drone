tutorial:
connect everything to the pi as listed below wiring and attach the pi to the power bank and
the camera to the pi, then flash the code to the pi from github and then use a laptop or 
chromebook (that is on the same network to controll the pi using it's ip http://youre pi's ip adress:5000 )
wiring:
32 to Left servo signal
33 to Right servo signal
6	to Servo GND
2 to servo pluss
